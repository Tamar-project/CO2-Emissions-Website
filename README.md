# Tamar-Project

## Titel  
Tamar-Project – Eine moderne Webanwendung zur Berechnung und Darstellung des persönlichen CO2-Footprints.  

## Funktionen  
- Mehrseitige Struktur (Startseite, Impressum, Datenschutz, Kontakt)  
- Datenerfassung und Verarbeitung in `daten.html`  
- Individuelles Styling mit `styles.css`  
- Responsives Design für verschiedene Geräte  
- Anpassbare Bilder (`banner3.jpg`, `logo.jpg`)  

## Technologien  
- HTML  
- CSS  
- JavaScript  
- Bootstrap  

## Nutzung  
1. Lade die Projektdateien herunter oder klone das Repository.  
2. Öffne `index.html` in deinem Browser, um die Anwendung zu starten.  

## Dateien im Projekt  
```
.vscode/          # Editor-Konfigurationen  
.DS_Store         # Systemdatei (kann ignoriert werden)  
banner3.jpg       # Bannerbild der Website  
logo.jpg          # Logo der Website  
daten.html        # Daten-Erfassungsseite  
datenschutz.html  # Datenschutzseite  
impressum.html    # Impressum  
index.html        # Startseite  
kontakt.html      # Kontaktseite  
script.js         # JavaScript für Interaktivität  
styles.css        # Eigene CSS-Stile  
README.md         # Projektbeschreibung (diese Datei)  
```
